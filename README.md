# MoreRVers-2026.11.2
UE4SS host-side mod for RV There Yet? that raises the multiplayer cap above the vanilla 4 players (1-24, default 8). Only the host needs it. v1.0.2 keeps the cap applied through game init, map load, player logins and session updates, fixing the fifth-player "unknown error" on game builds 1.3.20488+. Tested on 1.4.1.21945 with 5 players.
